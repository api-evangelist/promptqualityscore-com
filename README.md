Prompt Quality Score (PQS) provides a quality gate for AI prompts, scoring them across eight dimensions such as clarity, specificity, context, constraints, output format, role definition, examples, and chain‑of‑thought structure. Users can paste or edit prompts to receive a numeric score and detailed feedback, helping them improve prompt engineering before deploying to production. PQS offers a free tier for limited use and subscription plans starting at $19.99 per month for unlimited scoring, targeting developers, prompt engineers, and AI product teams seeking reliable prompt performance.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Prompt Quality Score: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
